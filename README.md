# Cybersecurity Labs

This repository contains my personal cybersecurity lab documentation and learning notes as I progress through practical cybersecurity training.

## About

The purpose of this repository is to document my hands-on experience, reinforce my learning, and build a professional cybersecurity portfolio.

The documentation includes:

- Personal notes
- Commands used during labs
- Tool configurations
- Scripts used/written by me
- Learning outcomes
- Diagrams created by me
- Permitted screenshots of my own lab environment

This repository does **not** contain copyrighted course material, lab manuals, answer keys, or any content that violates the policies of the training providers.
