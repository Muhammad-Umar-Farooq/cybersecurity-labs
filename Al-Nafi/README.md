# Al Nafi Labs

This directory contains documentation for the hands-on labs completed as part of the Al Nafi Diploma in Cloud & Cyber Security (DCCS).

The documentation focuses on practical skills, commands, configurations, and lessons learned.

## Modules

- Linux & Industrial Security Basics
- VA - Vulnerability Assessment
- WAPT - Web Application Penetration Testing
- NPT - Network Penetration Testing
- WSTG - Web Security Testing Guide
