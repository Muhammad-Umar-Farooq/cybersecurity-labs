# Linux & Industrial Security Basics

This module covers fundamental Linux administration and command-line skills commonly used in cybersecurity and system administration.

Topics include:

- File system navigation
- File and directory management
- User and group management
- Shell scripting
- Networking tools
- Package management
- Process management
- Permissions and ownership
- Logging and monitoring
- Storage management
- Firewall configuration
- Basic system administration
- and more...

Each numbered folder contains my personal notes, commands, observations, and permitted screenshots for the corresponding lab.
